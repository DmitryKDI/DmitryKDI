# Ключи провайдеров

Положите сюда файл, выданный в личном кабинете провайдера, — и всё. Ничего
вводить в интерфейсе не нужно, правки в коде и в переменных окружения тоже
не нужны: сервер сам находит ключ при запуске.

Имя файла произвольное, но удобнее назвать по провайдеру — `gigachat.txt`:
если файлов несколько, берётся тот, в имени которого есть название
провайдера из настроек. Расширение — `.txt`, `.key`, `.env` или без него.

Формат не важен. Принимается и голый ключ одной строкой, и выгрузка из
личного кабинета целиком: ключ находится в тексте по виду строки.

## Почему не в репозитории

Содержимое каталога не попадает в git (см. `.gitignore`) и не может туда
попасть случайно. Ключ принадлежит машине и учётной записи, а не коду: в
общем репозитории он становится общедоступным, и любой, кто получил копию
кода, тратит чужой лимит от вашего имени. По той же причине ключ не
«вшивается в программу» — просьба сделать это означает выложить его в
открытый доступ.

## Почему файл, а не поле в интерфейсе

Введённый в интерфейсе ключ живёт в базе, а база — производное: её
пересобирают, чистят, переносят. Файл здесь переживает и обновление
программы, и пересоздание базы (Г.113).

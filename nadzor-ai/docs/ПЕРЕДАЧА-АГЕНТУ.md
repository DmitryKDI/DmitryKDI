## Что осталось / не проверено

1. Полная сборка образов `docker/server.Dockerfile` и `docker/ml.Dockerfile`
   на машине с Интернетом (в песочнице apt внутри сборки недоступен —
   собирались облегчённые варианты) и `scripts/offline/prepare_bundle.sh`.
2. Прогон с GPU (vLLM + Qwen2.5-VL-7B): качество на реальных комплектах —
   только на стенде (окна проверки объявят организаторы после дедлайна).
3. Настоящий ClamAV в составе не запускался (проверено заглушкой протокола clamd).
4. Вёрстка протокола по Приложению № 2 ТЗ — шаблон не получен.
5. Решения на подтверждение пользователем: Redis 7.2 (BSD) вместо 7.4;
   модель эмбеддингов `paraphrase-multilingual-MiniLM-L12-v2` (аналог
   all-MiniLM-L6-v2 из ТЗ, многоязычный).
6. Пользователь просил промт для независимой проверки по ТЗ — актуальная
   версия у пользователя (файл «PROMPT-проверка-по-ТЗ.md»); по результатам
   такой проверки исправлять расхождения.

## Команды (из `nadzor-ai/`)

```bash

make lint

cd frontend && npm test && npm run build
```

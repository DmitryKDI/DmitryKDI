# Экономика решения

## 1. Формула эффекта

Эффект считается от сокращения времени подготовки инспектора к выездной проверке.
Формула вынесена в конфигурацию региона (`config/regions/moscow.yaml`) и
раскрывается по клику на дашборде — заявлять эффект голословно нельзя.

```
Сэкономленные часы = Число обработанных документов
                   × Нормативное время ручной проверки одного документа

Денежный эффект    = Сэкономленные часы × Стоимость часа работы инспектора
```

Значения по умолчанию для города Москвы:

| Параметр | Значение | Основание |
|---|---|---|
| Нормативное время ручной проверки документа | 0,35 ч (21 минута) | Экспертная оценка: сверка акта освидетельствования с проектом, паспортом качества и протоколом испытаний |
| Стоимость часа работы инспектора | 1 450 ₽ | Оценка полной стоимости рабочего часа с учётом накладных расходов |

Оба значения — параметры конфигурации. При внедрении они заменяются данными
заказчика по результатам хронометража, формула не меняется.

## 2. Расчёт на демонстрационном контуре

| Показатель | Значение |
|---|---|
| Объектов в контуре | 3 |
| Документов в контуре | 1 806 |
| Сэкономлено часов | 632 |
| Денежный эффект | 916 тыс. ₽ |

Расчёт приведён для трёх объектов. Отдел надзора ведёт десятки объектов
одновременно, поэтому эффект масштабируется линейно числу объектов.

## 3. Что именно сокращается

Сокращается не проверка как таковая, а **подготовка к ней**: поиск расхождений
между комплектами вручную. Инспектор получает готовый перечень мест, требующих
внимания, с указанием листа документа и пункта норматива.

Время выезда и оформления результатов не сокращается — система не подменяет
должностное лицо и не совершает юридически значимых действий.

## 4. Второй источник эффекта: полнота выявления

Ручная сверка полного комплекта физически невозможна: инспектор проверяет
выборку. Система проверяет комплект целиком. Формальные нарушения —
хронология, комплектность, арифметика объёмов, действительность допусков —
находятся детерминированными правилами полностью.

Этот эффект в денежном выражении не оценивается: он выражается в снижении риска
пропуска нарушения, влияющего на безопасность объекта.

## 5. Модель поставки

| Вариант | Описание |
|---|---|
| Защищённое облако региона | Веб-приложение в контуре субъекта, доступ через браузер без установки на рабочие места |
| Контур заказчика | Развёртывание в инфраструктуре надзорного органа, целевая операционная система — Astra Linux SE |

Лицензирование по числу инспекторов либо по числу объектов под надзором.
Данные не покидают контур: языковые модели подключаются только из числа
размещённых в Российской Федерации, что проверяется политикой роутера
провайдеров.

## 6. Масштабирование по стране

Подключение нового субъекта Российской Федерации — загрузка нормативного пакета
региона, а не доработка кода:

```
config/regions/<код>.yaml   нормативная база, классификатор, формы документов,
                            параметры экономики, адреса интеграций
```

Стоимость подключения региона складывается из подготовки нормативного пакета и
настройки интеграций с региональными системами. Разработка при этом не требуется.

## 7. Расширение периметра

Тот же механизм сравнения состояний применим к экспертизе проектной документации,
строительному контролю заказчика и приёмке объекта. Меняется набор переходов и
нормативный пакет, ядро остаётся прежним.

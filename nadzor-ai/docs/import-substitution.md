# Импортозамещение

## 1. Языковые модели

Ключевое требование: данные не покидают контур, модель размещена в Российской
Федерации. Реализовано политикой роутера провайдеров, а не соглашением.

| Провайдер | Размещение | Назначение |
|---|---|---|
| GigaChat | Российская Федерация | Продуктивный контур |
| YandexGPT | Российская Федерация | Продуктивный контур, перепроверка вторым провайдером |
| Локальное развёртывание (vLLM) | Изолированный контур заказчика | Целевой вариант для объектов с повышенными требованиями |
| Claude | Зарубежное размещение | Только разработка на синтетических данных, в продуктиве запрещён |
| Заглушка | Локально | Тесты и офлайн-демонстрация |

Политика `require_sovereign_for_protected_objects` в `config/providers.yaml`
запрещает выбор провайдера с зарубежным размещением для объектов, отмеченных как
защищённые. Проверка выполняется в `ProviderRouter.select`, обход из интерфейса
невозможен.

Переключение провайдера — правка одной строки конфигурации без пересборки.

## 2. Программная платформа

| Слой | Решение | Замещение |
|---|---|---|
| Операционная система | Astra Linux SE (целевая) | Реестр отечественного ПО |
| Система управления базами данных | PostgreSQL 16 | Свободное ПО, есть отечественные сборки (Postgres Pro) |
| Язык и среда выполнения | Python 3.12, Node.js 22 | Свободное ПО |
| Веб-сервер | nginx | Свободное ПО, есть отечественные сборки (Angie) |
| Оркестрация | Docker Compose, далее Kubernetes | Свободное ПО, совместимо с отечественными платформами |
| Хранилище файлов | S3-совместимое | Совместимо с отечественными объектными хранилищами |

Проприетарных компонентов с зарубежной лицензионной привязкой в составе нет.

## 3. Криптография

Собственная криптография не разрабатывается. Проверка электронной подписи по
ГОСТ Р 34.10-2012 выполняется сертифицированными средствами, подключаемыми на
стороне контура заказчика; система хранит только результат проверки.

## 4. Библиотеки обработки документов

| Библиотека | Лицензия | Назначение |
|---|---|---|
| PyMuPDF | AGPL-3.0 / коммерческая | Разбор PDF, отрисовка листов |
| reportlab | BSD | Формирование демонстрационных документов |
| python-docx | MIT | Проекты актов и предписаний |
| ezdxf | MIT | Сравнение чертежей |

Лицензия PyMuPDF требует внимания при поставке в закрытом контуре: возможен
переход на pdfium либо приобретение коммерческой лицензии. Вопрос вынесен в
дорожную карту как решение уровня закупки, а не разработки.

## 5. Что проверяется автоматически

- Состав зависимостей фиксирован по версиям, SBOM формируется в формате CycloneDX.
- `pip-audit` проверяет известные уязвимости, `trivy` — образы контейнеров.
- Тест политики роутера не даёт выбрать зарубежного провайдера для защищённого
  объекта.

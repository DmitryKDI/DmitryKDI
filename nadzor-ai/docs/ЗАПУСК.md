# Как запустить и что нажимать

## Один раз: ключ ГигаЧата

Ключ **не хранится в репозитории** и не передаётся в коде. Создайте в корне
`nadzor-ai/` файл `.env` (он уже в `.gitignore`):

```
GIGACHAT_CREDENTIALS=<ключ авторизации из личного кабинета, строка Base64>
GIGACHAT_SCOPE=GIGACHAT_API_PERS
# Раскомментируйте, если на машине нет корневого сертификата НУЦ Минцифры
# (симптом: SSL: CERTIFICATE_VERIFY_FAILED при первом же вызове)
GIGACHAT_CA_BUNDLE=false
```

Ключ можно ввести и в интерфейсе (карточка «Настроить ИИ») — тогда он ляжет
в базу настроек. Файл `.env` удобнее: задал один раз при развёртывании, и
инспектор не вводит ничего.

## Запуск

```bash
cd nadzor-ai
./scripts/start-all.sh          # Linux / WSL
```

Windows — `START-NADZOR.bat` (тот же скрипт через WSL).

Скрипт сам ставит зависимости, освобождает порты и поднимает два процесса:

| Порт | Что |
|---|---|
| 8010 | движок разбора документов (FastAPI) |
| 5173 | интерфейс (Vite, проксирует на 8010) |

Открыть: **http://localhost:5173**. Остановить — Ctrl+C в том же окне.

## Что нажимать

1. **Загрузите документы** в две зоны: «Проектная документация» и «Рабочая /
   исполнительная». Раздел тома определяется сам; если ошибся — исправьте
   вручную, ручной выбор побеждает автоматику.
2. **«Разобрать»** в карточке 1 (ПД). Состав тома считается всегда, даже без
   связи с моделью; требования — только при рабочей связи.
3. **«Разобрать»** в карточке 2 (РД) — то же самое для рабочей документации.
   Если связного текста в ней нет (обычное дело), покажется состав тома.
4. **«Сверить»** в карточке 3 — соответствие РД требованиям ПД. Результат:
   подтверждено / требует проверки (с листами) / не проверялось.

Связь с моделью проверяется **до** разбора: при обрыве прогон остановится с
явной причиной, а не выдаст пустую сводку за результат.

## Хранилище

Оригиналы лежат в отдельной базе `data/file_store.db` — одинаковые файлы
хранятся один раз. Каталог `packages/backend/uploads/` — только кэш,
удаляется в любой момент, файлы восстановятся из базы.

Карточка «Хранилище документов» в интерфейсе показывает занятое место и даёт
две кнопки: убрать по сроку хранения и освободить кэш. Оригинал, на который
ссылается загруженный документ, не удаляется никогда.

Лимиты и срок хранения — там же в настройках: размер файла, число страниц,
вес одной части (тяжёлый том режется на части, нумерация листов остаётся
исходной), срок хранения в днях.

## Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| «связь с провайдером не прошла» | проверьте `GIGACHAT_CREDENTIALS`; при `CERTIFICATE_VERIFY_FAILED` добавьте `GIGACHAT_CA_BUNDLE=false` |
| порт занят | закройте прошлый запуск: `pkill -f 'uvicorn app.main:app'` |
| «файл больше допустимого» | лимит в настройках, по умолчанию 512 МБ |
| разбор идёт долго | том в сотни листов — это десятки вызовов модели; прогресс виден в карточке |

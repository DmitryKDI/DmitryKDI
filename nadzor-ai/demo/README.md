# Демонстрационные материалы

## Прототип для показа

`nadzor-prototype.html` — самодостаточная страница: открывается двойным щелчком
в любом браузере, без сервера, без установки и без сети. Внутри — реальные
результаты анализа демонстрационного комплекта и изображения листов документов.

Что в нём работает:

- переключение роли: инспектор → начальник отдела → аудитор;
- дашборд инспектора со своими объектами и приоритетами;
- сводка начальника отдела: у кого сколько объектов, что найдено, где просрочены предписания;
- мастер нового анализа: подтягивание карточки по номеру разрешения, загрузка файлов
  перетаскиванием, выбор переходов, прогресс по этапам;
- журнал расхождений с указанием документа и листа для требования и для факта;
- просмотр листа документа с подсветкой области, к которой относится вывод;
- карта внимания с печатью и отметками «проверено»;
- журнал аудита с настоящей цепочкой SHA-256: кнопка «Подделать запись» ломает проверку.

`materialy-zashchity.html` — сценарий пятиминутной демонстрации, тезисы выступления,
разбор защиты от инъекций и ответы на неудобные вопросы.

## Как пересобрать прототип

Прототип собирается из исходников `prototype-src/` и данных, которые выдаёт
работающая система:

```bash
make data                                   # демонстрационный комплект документации
PYTHONPATH=. .venv/bin/python scripts/analyze_demo.py OBJ-001   # проверка анализа
python3 demo/prototype-src/build.py         # сборка страницы
```

Данные для страницы (`demo.json`, `pages.json`) формируются прогоном анализа и
отрисовкой листов документов; пути заданы в `build.py`.
